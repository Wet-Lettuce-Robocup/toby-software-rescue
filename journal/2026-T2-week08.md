# 08/06/2026 - 11/06/2026

### What I worked on:
Worked on getting a model compiled. After a lot more changes to python script, I got a compiled file! Further changed structure of repository so that I can add custom service messages. Worked on ml_vision_node, adding core functionality to read from camera publisher, and functionality to publish inference to '/ml_rescue/inference_stream'. Also worked on properly setting up state machine to switch between different parts of rescue when conditions are met, including adding a custom .srv service to manually change the state of the state machine for debugging purposes. I then made some test scripts to test the accuracy of the .hef model running on the Raspberry Pi AI Hat+ 2. This took a while to set up, as the documentation isn't very well maintained.

### Reflection
Whilst I was trying to test inference on the NPU, I kept running into errors, stemming from following outdated documentation. Eventually I was able to get everything working to some extent, mainly through trial and error.

### Decisions made
I want to perservere with using the AI Hat, as it should offload processing of images, allowing the Raspberry Pi to run faster in doing other tasks. I future-proofed the compiling process by adding config files for when I want to expand my model to accommodate green/red detection and more. Even though it is taking way too long to get it working, I hope that this will work out in the long term, rather than ditching the AI hat and just sticking to the .pt or .onnx model which won't be fully optimised.
