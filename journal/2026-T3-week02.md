### What I worked on:
More bugfixes, including problems with servos, movement and some random crashes, and finalising documentation for submission. Some changes to make sure that the state loop isn't being blocked when movement action is waiting.

### Reflection
Mostly small changes this week, but I had a lot of trouble with the asynchronous of ROS. Servos not moving, robot driving before servos moved because I can't use time.sleep(). I settled with using states within states to keep the state machine running without being held up, but now it will wait for movement action to finish before moving to the next sub state.

### Decisions made
States within states, allowing the state machine to return when only waiting on movement services and not execute any other code until movement services returns not busy. This is just best practice, as far as I am aware.
